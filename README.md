# Numerical Solver for the Lane-Emden Equation using 4th-Order Runge-Kutta (RK4)

## 🎯 Overview
This repository provides a complete infrastructure to solve the Lane-Emden equation numerically for different polytropic indices ($n$). It includes a comparative study between classical stellar equilibrium and quantum degeneracy states in white dwarfs.

## 🛠️ Tech Stack & Methods
- **Numerical Integration:** Custom implementation of the 4th-Order Runge-Kutta (RK4) algorithm to solve non-linear ordinary differential equations (ODEs).
- **Boundary Condition Handling:** Algorithmic management of coordinate singularities at the origin ($x \to 0$).
- **Statistical Mechanics:** Modeling of completely degenerate non-relativistic electron gases using Fermi-Dirac statistics and Sommerfeld expansions.
